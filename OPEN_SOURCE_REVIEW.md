# Open-source release review

Status: **PREPARATION ONLY — NOT APPROVED FOR MERGE**.

This branch stages an MIT license and community documentation. Before merging, a maintainer must verify:

- [ ] Authorship and licensing rights for all code, schemas, registry content, and dependencies.
- [ ] No credentials, tokens, sensitive data, proprietary assets, or confidential architectural details in the complete git history.
- [ ] Exact license holder/year wording is approved.
- [ ] Test suite and validation commands pass on a clean checkout.
- [ ] Third-party components have compatible licenses and required notices.
- [ ] Repository scope is intended for unrestricted reuse, including commercial reuse.
- [ ] Security reporting method is available to contributors.

The absence of results in simple secret-keyword searches is **not** a complete secret scan.
