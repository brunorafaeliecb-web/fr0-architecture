# Security policy

## Reporting a vulnerability

Please do **not** publish secrets, exploit details, credentials, or personal data in a public issue.

Contact the repository maintainer privately via the GitHub profile linked to this repository and ask for a private reporting channel. If GitHub private vulnerability reporting is enabled, prefer that mechanism.

Include affected versions, reproducible steps, impact, and mitigation suggestions, but never include live credentials.

## Supported versions

The repository is currently maintained as a baseline implementation pack. No long-term security support schedule is promised. The maintainer will evaluate reports case by case.
